# ⭐ Star Rating Widget

A simple and interactive **Star Rating Widget** built using HTML, CSS, and JavaScript.

Users can select a rating from **1 to 5 stars**, preview ratings by hovering over the stars, and reset the selected rating.

## 🚀 Demo

You can deploy this project using:

- Vercel
- Netlify
- GitHub Pages

## 📌 Features

- ⭐ 5 clickable stars
- 🖱️ Hover preview effect
- ⭐ Selected rating remains active
- 📊 Displays the current rating
- 🔄 Reset rating button
- ✨ Smooth hover animation
- 📱 Responsive design
- 🎨 Modern and clean UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- `data-*` Attributes
- `classList`
